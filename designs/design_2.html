Figma Spec Elements • UX Engineering Report

Reimagining minicabs.co.uk UX

The previous UI designs utilized rigid table boundaries, sharp shadows, and lacked contemporary mobile spatial layouts. This Figma implementation redesigns the experience around sleek, modern card-based mobile patterns, bringing the aesthetics in line with global leading dispatch apps like Uber.

Secure Face ID Verification Access

Integrated local system-level biometric triggers directly within the secure login flow wrapper. Enhances accessibility and cuts authentication delay down to 1.4 seconds.

Unified Terminal & Airport Selector

Cleaned up the tabular structures into high-fidelity dynamic row components. Dedicated segments for airports, railway hubs, and user favorites with prominent icons for low-friction selection.

System Color Contrast Compliance

Maintained signature Brand Blue (#0D3276) and Green (#76BC21) but introduced soft background neutrals (#F8FAFC) to dramatically reduce ocular fatigue during night bookings.

Selected Prototype Resolution: iPhone 13/14 Pro Fit
