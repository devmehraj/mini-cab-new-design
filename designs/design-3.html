Reimagined minicabs.co.uk UX

We have transformed the original dense, high-contrast grid layouts into a modern, frictionless user interface modeled after Uber's flagship architecture. By cleaning the boundaries, implementing high-fidelity SVG/Vector routes, and standardizing typography around Plus Jakarta Sans, we have dramatically streamlined the ride-booking loop.

Sleek, Flat Surface Layouts

Swapped out heavy custom gradients for neutral flat tiles with single-pixel boundaries (#EBEBEB), matching modern design principles.

Dynamic Vehicle Tier Selectors

Unified dispatch confirmation screens with interactive standard, exec, and group-carry vehicle choices containing real-time ETA countdown tags.

Frictionless Favourites Access

Introduced customizable quick-book shortcuts on the main dashboard tab, triggering booking drawers in exactly one press.
